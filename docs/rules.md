# Rules

One section per catalog rule, generated by
``scripts/generate_rule_docs.py``. Do not edit by hand; regenerate after
changing ``src/astart/rules/catalog/``.

## CAL001 — Argument passed positionally

- **Key:** `calls.missing-keyword`
- **Severity:** error
- **Fixes:** `calls.add-keywords`

Keyword arguments keep call sites readable and safe when parameters are reordered.

## DOC001 — Public definition without a docstring

- **Key:** `docs.missing-docstring`
- **Severity:** info
- **Fixes:** none

Public functions and classes owe their callers a sentence of prose.

## DOC002 — Parameter missing from docstring

- **Key:** `docs.missing-parameter`
- **Severity:** error
- **Fixes:** `docs.add-parameter-entries`

Every parameter of a documented function belongs in its Args section.

## DOC003 — Docstring documents a missing parameter

- **Key:** `docs.stale-parameter`
- **Severity:** error
- **Fixes:** `docs.heal-parameter-rename`, `docs.remove-stale-entries`

A docstring entry for a parameter the function no longer takes misleads readers.

## DOC007 — Docstring has stray whitespace

- **Key:** `docs.untidy-docstring`
- **Severity:** info
- **Fixes:** `docs.tidy-docstring`

Trailing spaces, blank-line runs and misaligned lines inside a docstring add noise.

## STR001 — Final constant outside the Constants class

- **Key:** `structure.loose-final-constant`
- **Severity:** warning
- **Fixes:** `structure.group-constants`

Module constants live in one @final class Constants so they have a single place to be found and documented.

## TYP001 — typing.Any usage

- **Key:** `typing.no-any`
- **Severity:** error
- **Fixes:** none

Any switches type checking off for the value it annotates; use a precise type, a protocol or a generic.

## TYP003 — Missing type annotation

- **Key:** `typing.missing-annotation`
- **Severity:** error
- **Fixes:** `typing.add-none-return`, `typing.add-noreturn`, `typing.add-inferred-annotation`, `typing.synthesize-protocol`, `typing.synthesize-typevar`, `typing.synthesize-self`

Parameters and return values need annotations so checkers and readers know the contract; hints are written only when the evidence supports them.

## TYP004 — Uppercase module global is not Final

- **Key:** `typing.uppercase-global-not-final`
- **Severity:** error
- **Fixes:** `typing.add-final`

An uppercase module global reads as a constant; declaring it Final makes the checker enforce that.

## TYP005 — Instance attribute without annotation

- **Key:** `typing.missing-attribute-annotation`
- **Severity:** info
- **Fixes:** `typing.add-attribute-annotation`

An annotation on the first write documents the attribute and pins its type for every method.

## TYP007 — Local variable without annotation

- **Key:** `typing.missing-variable-annotation`
- **Severity:** info
- **Fixes:** `typing.add-variable-annotation`

A local whose type the evidence proves can say so, in modules whose author annotates locals or when asked with --annotate-variables.

## WSP001 — Excessive blank lines

- **Key:** `whitespace.excessive-blank-lines`
- **Severity:** info
- **Fixes:** `whitespace.collapse-blank-lines`

PEP 8 allows at most two blank lines at module level and one inside a block; longer runs are almost always accidental.

## WSP002 — Trailing whitespace

- **Key:** `whitespace.trailing-space`
- **Severity:** info
- **Fixes:** `whitespace.strip-trailing-space`

Trailing whitespace is invisible in diffs and editors, and most tools strip it automatically.
